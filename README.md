Expense Tracker 
🚀Features

Expense Logging: Easily add your daily expenses with categories and descriptions.

Budget Monitoring: Keep track of your spending habits in real-time.

Data Persistence: Automatically saves your records so you don't lose data between sessions.

Beginner Friendly: Clean code structure, perfect for understanding data management and file handling.

🧠Concepts Used

Python Programming

File Handling (CSV/JSON): Used to store and retrieve transaction history permanently.

Data Structures: Used Lists and Dictionaries to organize transaction data efficiently.

Logic: Implemented loops and conditional statements to filter and display financial reports.
